# LawEverything

**조달청 실무자를 위한 법령 즉시검색 + 위임·인용 관계 그래프 (내부망/오프라인)**

법령정보센터에서 조문 PDF를 내려받아 뒤지는 대신, 조달 법령군을 **즉시 검색**하고
법 사이의 **위임(법→시행령→규칙)** 과 **인용(조문↔조문)** 관계를 그래프로 따라가는 도구.

> ⚠️ 현재 `data/procurement-laws.json`은 **프로토타입 검증용 축약 샘플**입니다. 실제 법령 원문이 아니며,
> 온라인 빌드 단계에서 국가법령정보 오픈API / [korean-law-mcp](https://github.com/chrisryugj/korean-law-mcp)의 데이터로 대체됩니다.

## 왜 이 구조인가 — 내부망(폐쇄망) 전제

조달청 실무는 폐쇄망에서 돌아가 실시간 API 호출이 불가능하다. 그래서 **관계 계산과 데이터 수집을 분리**한다.

```
┌── 온라인 빌드 단계 (인터넷 PC) ─────────────────┐        ┌── 내부망 런타임 ──────────┐
│  오픈API / korean-law-mcp 로 조달 법령군 수집     │  반입   │  web/index.html            │
│  → 규칙기반 관계추출(AI 없음) → 정적 스냅샷        │ ─────▶ │  외부 의존성 0             │
│    (web/index.html = 텍스트 + 그래프 내장)        │        │  즉시검색 · 클릭 탐색 (오프라인) │
└──────────────────────────────────────────────┘        └──────────────────────────┘
        ▲ 법 개정 반영은 이 단계만 주기적으로 재실행 (예: 월 1회)
```

- **데이터 수집은 배치**가 강제 — 폐쇄망이라 실시간 API 불가.
- **관계 계산은 AI 0%** — 위임은 오픈API가 구조화 데이터로 제공, 인용은 순수 정규식 + 문맥 상태머신으로 추출.
- **런타임은 항상 즉각** — 스냅샷을 미리 구워두므로 클릭마다 재계산 없음.

## 실행

```bash
node src/extract.mjs   # 관계 추출 결과·통계만 출력 (검증용)
node src/build.mjs     # web/index.html 생성 (스냅샷+그래프 내장)
```

생성된 `web/index.html`은 더블클릭으로 열면 됨 — 서버·인터넷 불필요. (또는 `npm run serve`)

## 관계 추출 규칙 (`src/extract.mjs`, AI 없음)

- **위임**: 법률 조문의 `대통령령으로 정한다` → 계열 시행령, `기획재정부령으로 정한다` → 계열 시행규칙.
- **인용** (왼→오 스캔, 문맥 `lastLaw` 유지):
  - `「법명」 제N조` — 명시적 타법 인용 (스냅샷에 없으면 외부법 노드 생성)
  - `법 제N조` — 상위 법률 (시행령/규칙에서)
  - `영 제N조` — 같은 계열 시행령 (시행규칙에서)
  - `같은 법 제N조` — 직전에 명시된 법 (상태머신)
  - `제N조` — 같은 법령 내 인용

## 구조

```
data/procurement-laws.json  스냅샷 (샘플)
src/extract.mjs             규칙기반 관계추출기 (+CLI 통계)
src/build.mjs               스냅샷→자족형 페이지 빌드
src/template.html           UI 템플릿 (바닐라 SVG 포스그래프)
web/index.html              ★ 산출물: 오프라인 즉시검색·관계 그래프
```
