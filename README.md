# 뭐하려 했더라

**전화 받다 떠오른 일을, 잊기 전에 던져두는 곳.**

마감·점검 **시각만** 적어 두면 "오늘 할 일"을 프로그램이 알아서 위로 올려 주는 개인 업무 보드.<br/>
인터넷도 · 설치도 · 계정도 필요 없습니다.

## 이런 적, 있으시죠

- **전화를 받는 중에** "아 이거 해야 하는데" 싶은 일이 생기는데, 메모할 곳을 찾는 사이 통화가 끝난다
- **적어는 뒀는데** 포스트잇·메모장·수첩에 흩어져 있어서, 오늘 뭘 해야 하는지는 결국 다시 훑어야 안다
- **할 일 앱을 써 보자니** 계정을 만들라 하고, 적은 내용이 클라우드로 나가고,
  애초에 **인터넷이 안 되는 PC**라 설치조차 못 한다

그래서 만든 **혼자 쓰는 업무 보드**입니다.
공무원 내부망(인터넷 차단·관리자 권한 없는 PC)에서 쓰려고 만들었습니다.

exe 파일 하나로 돌아갑니다. 설치도, 계정도, 인터넷도 필요 없습니다.

## 그래서 뭐가 달라지나

| 그동안 | 이 프로그램 |
|---|---|
| 통화 중에 메모장을 찾아 연다 | 어느 화면에서든 `Ctrl+Alt+Space` → 적고 `Ctrl+Enter`. **끝** |
| 할 일 카드를 매일 손으로 옮긴다 | **옮기지 않습니다.** 적어 둔 시각을 보고 프로그램이 칸을 정합니다 |
| "오늘 뭐부터 하지" 하고 목록을 훑는다 | 칸 안에서 **먼저 다가오는 일이 맨 위**. 위에서부터 하시면 됩니다 |
| 매주 반복되는 보고를 매번 새로 적는다 | **주기 업무**를 한 번 등록하면 정해둔 때에 알아서 생깁니다 |
| 저장 버튼, 동기화, 계정 | 고치는 즉시 저장됩니다. 바깥으로 나가는 것은 없습니다 |
| 백업이 어디 있는지 모른다 | 내가 고른 폴더 하나에 전부. 폴더째 복사하면 이사 끝 |

```
전화 중    →  Ctrl+Alt+Space  →  "○○청 김주무관, 견적서 재요청"  →  Ctrl+Enter
보드       →  [분류 대기] 에 카드 한 장
짬이 날 때 →  카드를 눌러 마감 7/30 15:00, 세부 할 일 "견적 도착 확인" 7/29 10:00
7/29 아침  →  그 카드가 [오늘 처리] 맨 위에 올라와 있습니다
7/29 10:00 →  알람 — 창이 뒤에 있어도 앞으로 나옵니다
```

## 카드를 손으로 옮기지 않습니다

이 앱이 다른 할 일 앱과 가장 다른 점입니다. **끌어다 놓는 기능이 아예 없습니다.**
대신 마감·점검 시각만 적어 두면 프로그램이 판단해 칸에 놓습니다.

| 칸 | 여기에 오는 일 |
|---|---|
| **분류 대기** | 마감일도 점검일도 아직 **하나도 정하지 않은** 일 |
| **오늘 처리** | 오늘이 마감이거나, 오늘 점검할 게 있거나, 이미 지난 일 |
| **진행 중** | 세부 할 일을 **하나라도 완료한** 일 (이미 손을 댄 일) |
| **예정 · 대기** | 시각은 정했지만 내일 이후라 아직 여유가 있는 일 |

칸은 어딘가에 저장된 값이 아니라 **화면을 그릴 때마다 지금 시각과 견줘 다시 계산**합니다.
그래서 아무것도 안 하고 하루가 지나도, 어제의 '예정'이 오늘 아침엔 '오늘 처리'에 가 있습니다.
자리를 옮기고 싶으면 카드를 눌러 **시각을 바꾸면** 됩니다.

> 남에게 넘겨 둔 일까지 나누고 싶다면 [설정] → **보드 모드 선택**에서 `시간·담당자` 방식으로
> 바꿀 수 있습니다. **본인/타인 × 오늘/오늘 외** 네 칸 + 분류 대기로 나뉩니다.

## 이렇게 씁니다

**던져 두기** — 화면 위 입력창에 적고 `Ctrl+Enter`(또는 `Ctrl+S`). 다른 프로그램을 보고 있다면
`Ctrl+Alt+Space` 로 작은 창을 불러서 적습니다. 둘 다 [분류 대기]로 들어갑니다.
쓰다 만 메모는 창을 닫아도, PC 가 꺼져도 사라지지 않고 다음 실행 때 자동 등록됩니다.

**단축키로 뜨는 작은 창** — `Ctrl+Alt+Space` 로 뜨는 화면은 세 가지 중에서 **직접 고릅니다**:
**내 업무 검색**(기본) · **빠른 메모** · **양식 메모**. 먼저 뜰 화면과 `Alt` 로 넘어갈 화면을
[설정]에서 각각 지정합니다. 검색 화면에서는 `↑`·`↓` 로 고르고 `Enter` 로 그 업무를 엽니다.

**제대로 정리하기** — 카드를 누르면 양식이 열립니다. 관련인(소속·이름·연락처), 식별정보
(입찰공고번호·SR번호 같은 것), 세부 할 일(단계마다 점검 시각과 **담당자**), 파일 링크, 마감 시각을
채웁니다. **쓰다 만 양식은 자동으로 임시저장**되니 `Esc` 로 닫아도 이어서 쓸 수 있습니다
(카드에 반영되는 건 [저장]을 눌렀을 때뿐입니다).

**반복되는 일** — [설정] → **주기 업무 입력·관리**에서 내용과 주기(매주 요일 / 매월 며칠)를
한 번만 등록합니다. 카드가 **언제 보드에 나타날지도 고릅니다** — `주초(월요일) 한 주치 일괄`(기본,
그 주 할 일이 월요일 아침에 한꺼번에) · `하루 전` · `당일`, 기준 시각은 기본 06:00.
등록해 둔 주기 자체는 보드에 카드로 뜨지 않고, 실제 할 일만 그때그때 생깁니다.

**알람** — 마감·점검 시각이 되면 알림창이 뜨고 소리가 납니다(창이 뒤에 있어도 앞으로 나옵니다).
카드의 작은 점이 상태입니다: 빈 점(대기) → 빨강(울리는 중) → 초록(확인함).
시각 태그는 **지났거나 2시간 이내일 때만** 붉게 강조되고, 그 밖에는 중립색입니다.

**끝난 일 · 검색 · 달력** — 체크하면 [완료] 탭으로 갑니다(×로 지웠다면 알림에서 실행 취소).
검색은 메모·관련인·소속·담당자·번호·파일 이름 아무거나 걸리고, 연락처는 숫자만 쳐도 찾습니다.
달력에는 **진행 중인 일만** 나옵니다.

**전화번호부** — 자주 연락하는 관련인을 [전화번호부] 탭에 모아 둡니다. 메모는 자유 형식이지만
전화번호부는 **"명함 한 장"** — 소속·이름·연락처가 모두 있는 사람만 저장됩니다(일부만 아는
관련인은 메모에 자유롭게 적으세요). 채우는 방법: 직접 입력 · **[새로고침]**(업무에 적어둔 관련인
회수) · **엑셀 파일**(첫 줄에 이름·소속·전화 제목) — 그리고 **양식을 저장하면 그 관련인이 자동으로
반영됩니다**. 저장해 두면 **바로 입력·미니 창·양식 메모에서 `@김철` 처럼 치는 순간 후보가 떠서**,
고르면 `@김철수` 태그가 들어가고 그 사람의 소속·연락처가 업무의 관련인으로 자동 첨부됩니다
(양식의 관련인 칸은 @ 없이 일부만 쳐도 검색). 양식을 열면 메모 아래 **@태그 칩**이 뜨는데,
클릭하면 그 사람과 엮인 업무가 한 팝업에 모입니다 — 이름 또는 연락처가 일치하는 업무를 전부
찾아주므로, 예전에 이름만 적었든 번호만 적었든 걸립니다.

**같은 건 두 번 적었을 때** — 보드에서 카드를 **끌어 다른 카드 위에 놓으면 하나로 합쳐집니다**.
메모는 이어붙고, 세부 할 일은 점검 시각 순서로 자동 정렬되며, 접수·마감은 둘 중 이른 쪽이
남습니다(마감을 놓칠 일이 없게). 잘못 합쳤으면 토스트의 [실행 취소]를 누르세요.

**보기 편하게** — 화면 색은 [설정]에서 밝게/어둡게(앱 전체가 함께 바뀝니다). 창은 **전체화면**과
**컴팩트(560px, 한 칸)** 두 가지이고, `Ctrl + 휠`로 화면 전체를 80~150%까지 키울 수 있습니다.

> 📖 화면 그림과 함께 더 자세한 안내는 [`사용 설명서.md`](./사용%20설명서.md) 에 있습니다.

## 시작하기

`최종 프로그램 산출물/뭐하려 했더라v{버전}.exe` 를 컴퓨터 아무 곳(바탕화면, D드라이브 등)에
복사해 더블클릭하면 바로 실행됩니다. **설치 과정도, 관리자 권한도 필요 없습니다.**

처음 실행하면 데이터를 보관할 폴더를 묻습니다. 고르면 그 안에 `뭐하려했더라_데이터` 폴더가
생기고, 업무 데이터와 자동 백업이 전부 그 안에만 저장됩니다. (건너뛰어도 되고, 나중에
[설정] → 저장 위치에서 언제든 옮길 수 있습니다.)

창의 ✕ 를 눌러도 프로그램은 **트레이(시계 옆)에 남아** 알람과 단축키를 계속 챙깁니다.
완전히 끄려면 트레이 아이콘을 우클릭해 [종료]를 고르세요.

**내 데이터는**

- **저장은 자동입니다.** 바꾸는 즉시 저장되니 저장 버튼을 찾지 않으셔도 됩니다.
- **혹시 저장이 안 되면 화면 맨 위에 빨간 경고가 뜹니다** (디스크가 꽉 찼거나, 저장 위치로 쓰던
  USB·네트워크 드라이브가 빠졌거나, 백신이 파일을 잠근 경우). 조용히 유실되지 않게 한 것입니다.
- **자동 백업**은 30분마다, 그리고 날마다 첫 백업본을 14일간 따로 보관합니다. 한꺼번에 많이
  지워지는 저장 직전에는 **덮어쓰기 전 스냅샷**을 따로 남깁니다.
- 시작할 때 데이터 파일이 손상돼 있으면 최근 백업으로 스스로 복구합니다(검사를 통과한 백업만
  씁니다). 어떤 경우에도 앱이 실행 불능이 되지는 않습니다.
- 모든 데이터는 **내가 고른 폴더 안에만** 있습니다. 인터넷으로 나가는 것은 아무것도 없습니다.
- 다른 PC 로 옮길 때는 [설정] → **JSON파일 백업**으로 파일 하나를 만들어 가져간 뒤,
  새 PC 에서 **JSON·DB파일 불러오기**를 하시면 됩니다. 보고용 **XLSX 내보내기**도 있습니다.

**자주 묻는 것**

- **인터넷이 안 되는 PC인데 쓸 수 있나요?** — 네. 웹폰트까지 포함해 외부 자원을 하나도
  쓰지 않습니다.
- **실행이 안 됩니다** — 구형 Windows 10 이라면 "WebView2 런타임"이 없을 수 있습니다
  (Windows 11 과 최신 10 에는 기본 내장). 전산 담당자에게 오프라인 설치를 요청하세요.
- **이미 켜져 있는데 또 실행하면?** — 새 창이 뜨지 않고 기존 창이 앞으로 나옵니다.
- **카드 위치를 직접 옮기고 싶어요** — 옮기지 않는 것이 이 보드의 특징입니다. 카드를 눌러
  마감·점검 시각을 조정해 주세요.

## 만들면서

기능은 단순한데 만드는 건 만만치 않았습니다. 몇 가지만 남겨 둡니다.

- **가장 무서운 건 잘못된 저장이었습니다.** 앱이 뜨자마자 빈 목록이 저장되면 기존 데이터를
  덮어씁니다. 그래서 불러오기가 끝나기 전에는 저장을 아예 막고, 저장은 항상 전체를 한 번에
  씁니다 — 반쯤 저장된 상태가 남을 자리를 없앤 것입니다.
- **조용한 실패를 없애는 데 시간을 많이 썼습니다.** 저장 실패 경고 배너, 대량 삭제 전 스냅샷,
  손상된 백업을 건너뛰고 더 오래된 정상 백업을 쓰는 복구가 전부 그래서 붙었습니다.
- **화면 꾸미기가 데이터 로드를 무너뜨린 적이 있습니다.** 테마 적용 한 줄이 실패했는데
  "데이터를 불러오지 못했습니다"가 뜨고 저장까지 막혔습니다. 지금은 둘을 분리했습니다.
- **만들었다가 걷어낸 것도 있습니다.** 시각 태그를 급한 정도에 따라 5색으로 나눴다가 어지럽다는
  피드백으로 임박 하나만 남겼고, 파일 검색 연동은 붙여 보니 검색이 느려져 통째로 뺐습니다.

## 개발

| 작업 | 명령 |
|---|---|
| 개발 실행 (핫리로드) | `npm run tauri dev` |
| 프론트 테스트 (node:test + jsdom, 128개) | `npm test` |
| 백엔드 테스트 (DB 라운드트립) | `cd src-tauri && cargo test --lib` |
| 릴리즈 빌드 | `npm run tauri build` → `src-tauri/target/release/wmhh-desktop.exe` |

- **Tauri 2(Rust) + SQLite**, 프론트는 번들러 없는 순수 HTML/CSS/JS(`src/`)입니다.
  요구 도구는 Rust(MSVC)와 Node.js.
- **Rust 는 저장만 담당합니다.** 자동 배치·알람·렌더 규칙은 전부 프론트(`src/`)에 있고,
  칸을 정하는 로직은 [`src/placement.js`](src/placement.js), 저장 경계는 `src/store.js` 하나입니다.
- DB 스키마 변경은 `src-tauri/src/db/migrations/` 에 **추가만** 하세요 — 자동 업데이터가 없는
  환경이라 설치본이 여러 버전을 건너뛰고 올라올 수 있습니다.
