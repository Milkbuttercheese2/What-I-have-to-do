# 뭐하려 했더라 소개영상 (v3.7.0)

| 파일 | 무엇 |
|---|---|
| `뭐하려했더라_소개영상_v3.7.0.mp4` | 약 4분 19초, 1920×1080 60fps, 내레이션 + 자막(멘트와 같은 문장) + 합성 배경음악. 시나리오 **"박조달 주무관의 하루"** — 출근(자동 실행) → ① 아침 보드(다섯 칸·요약 숫자·지난 시각 표시) → ② 전화 한 통(Ctrl+Alt+Space 빠른 메모, @ 전화번호부 자동완성, 관련인 자동 첨부) → ③ 업무로 다듬기(양식·세부 할 일 점검 시각 → 칸 이동, 프리셋, 파일 끌어다 놓기·링크, 메모 합치기) → ④ 알림·2쪽 보기·업무 종료 → ⑤ 다시 찾기(빠른 검색, 완료 업무 다시 진행, 하루 시간표, 완료 묶음) → ⑥ 관계도·전체 지도 → ⑦ 담당자 교체(인물 일괄 바꾸기, 엑셀 양식) → ⑧ 주기 업무 → ⑨ 테마·백업 → 마무리 |
| `원본/` | 다시 만드는 데 필요한 스크립트 |

'조달법령 흐름도' 시연 영상(koneps-flow `docs/시연/조달법령흐름도-심사용`)과 **같은 장면 엔진**(`원본/index.html` —
알약 → 창 전환·카메라 이동·커서·강조 테두리·자막), 같은 목소리(ElevenLabs), 같은 음악 합성기(`music.py`)·믹서(`mix.py`)를 쓴다.
소유자 피드백(시나리오로 더 많은 내용, 자막=멘트, 화질)에 따라 v3 로 다시 만들었다: 하루 업무 흐름을 따라 44문장, 자막은 읽는 문장 그대로, 화면은 2배율(3840×2160)로 갈무리해 확대해도 또렷하고 최종 압축은 CRF 14.

## 화면은 실제, 데이터는 예시

- 화면: 이 저장소의 `src/` 를 Edge 에 1920×1080(2배율)으로 그대로 띄워 갈무리했다(v3.7.0). 미니 창은 실제 `capture.html` 을 보드 위에 띄워 찍었다.
- 데이터: `원본/sample-data.mjs` — 사용 설명서 갈무리 예시에 관계도가 보이도록 몇 건을 더한 **가상의 예시**다.
- 내레이션: `원본/script.mjs`(읽는 소리 · 화면 자막), 음성 파일은 `원본/tts/*.mp3` 로 저장돼 있어 다시 만들 때 API 를 다시 부르지 않는다.
- 음악: numpy 합성(외부 음원 없음 — 저작권 문제 없음).

## 다시 만들기(`원본/`에서, 저장소 루트에 `npm install --no-save playwright-core` 가 되어 있어야 한다)

```bash
cp ../../../src/fonts/PretendardVariable.woff2 .
node capture.mjs        # 장면 갈무리 → shots/*.jpg, shots.json
node tts.mjs            # 문장별 음성(없는 파일만 새로 만든다 · 키는 조달법령 저장소 .env 에서 읽는다) → tts/, durations.json
node build.mjs          # 음성 길이로 자막·사건 시각 → timeline.js, cues.json
node stills.mjs         # (선택) 주요 순간 정지 화면 → stills/
python music.py && python mix.py
bash render-all.sh      # → clip.mp4
```

원고를 고치면 해당 문장의 `tts/<id>.mp3` 를 지우고 `node tts.mjs` 부터 다시 돌린다.
