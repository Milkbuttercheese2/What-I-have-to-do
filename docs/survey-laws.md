### 이번 조사의 결론 3줄

1. **현재 그래프에는 조문이 있는 법률이 3개뿐이다.** 국가계약법·조달사업법·전자조달법 가문 13문서가 전부고,
   나머지 765개 외부법 노드는 전원 스텁이다. "인용은 많은데 조문이 없는" 법령은 예외가 아니라 **기본값**이다.
2. scope.md §2.5가 놓친 축이 하나 있다 — **기재부 회계·물품 계열**(물품관리법·국고금 관리법·물품목록정보법).

3. 외부법 노드 765개 중 상당수가 **같은 법의 별칭 파편**이다(판로지원법 하나가 7개 노드로 쪼개짐).

### 12.1 현황

### 12.2 수집 전에 먼저 처리해야 할 것 — 외부법 노드 오염

외부법 765개 노드가 전부 서로 다른 법령인 것이 아니다. 세 종류의 오염이 섞여 있다.

**(a) 별칭 파편화** — 같은 법이 여러 노드로 쪼개진다.
- 판로지원법 = 7개 노드 (`…판로지원에 관한 법률`, `…(이하 "판로지원법"이라 한다)`, `판로지원법`, `판로지원법 시행령`, …)
- 지방계약법 = 12개 노드 (`지방계약법시행령`(50회)이 정식명 노드(27회)보다 많다)
- 물품관리법 = 6개 노드 (`물품관리법 시행령(이하 "영"이라 한다)` 같은 것 포함)
→ **`(이하 "X"라 한다)` 꼬리를 노드 키에서 떼어내는 정규화**가 필요하다. 안 하면 인용 통계가 전부 어긋난다.

**(b) 법령이 아닌 것** — 인용 1위(232회)가 「훈령·예규 등의 발령 및 관리에 관한 규정」이다.
이건 모든 행정규칙 말미의 **재검토기한 조항 상용구**라 실무 가치가 0에 가깝다.
같은 대상이 `훈령ㆍ예규…`(232) / `훈령·예규…`(19) / 영문 표기(2) 로 **가운뎃점 종류에 따라 3개 노드**로 갈라져 있기도 하다.
→ **수집 대상에서 제외 권고.** 이 문서의 66건에도 넣지 않았다.

**(c) 파서 잔여물** — `동법 시행령`(3), `특례규정`(3), `「소프트웨어진흥법`(여는 괄호 미제거, 1),
`조달청 불공정행위 신고센터(전화 1644-0412)`(1) 같은 노드가 실재한다.

### 12.3 이 목록에서 의도적으로 뺀 것
조달 판단이 아니라 **조달청 내부 행정**에만 걸리는 법령은 제외했다 — 국가공무원법(21), 공직자윤리법(5),
공무원여비규정(7), 국가공무원 복무규정(14), 보안업무규정(9), 감사 관련 규정 등.
인용 횟수는 적지 않지만 "몇 조항이더라"의 질문 대상이 아니다.
세법(부가가치세법 14·법인세법 10·소득세법 8·인지세법 5)도 같은 이유로 제외했다 — 필요하면 별도 판단.

## 14. 확인 못 한 것 (정직한 공백)

- **민법 식별자** — §10. 검색 API 특성으로 확보 실패. 유일한 미확인 항목.
- **소관부처** — 각 법령의 소관부처는 법령 구분(부령 종류)과 실무 통념으로 분류했다.
  `search_law` 응답에 소관부처 필드가 없어 **법제처 소관부처 코드로 교차확인하지 않았다.**
  `국가기술자격법`(고용부 소관을 회계 계열에 배치) 같은 편의적 배치가 있다.
- **하위법령 "없음" 판정** — `search_law` 부분매칭 결과에 나타나지 않은 것을 없음으로 적었다.
  display 3~6 으로 조회했으므로 **동명 접두 법령이 많은 경우 누락 가능성**이 있다.
  특히 국가재정법·중소기업기본법·공정거래법의 "시행규칙 없음"은 재확인 권장.
- **시행예정 개정** — `search_law` 가 자동 병기한 것만 옮겼다. 병기되지 않은 개정이 없다는 보장은 없다.
- **녹색제품법의 낮은 인용(3회)** — 의무구매법인데 인용이 적은 이유를 확인하지 않았다. 추정만 적었다.
- **전수성** — 이 목록은 ① 사용자 지목 ② scope.md §2·§2.5 ③ 현 그래프 외부법 노드 765개 교차대조로 만들었다.
  **조달청 홈페이지 법령정보 목록과는 대조하지 않았다.** 세 출처 모두에 없는 법령은 여전히 누락될 수 있다.
